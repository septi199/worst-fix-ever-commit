## The entry

> fix: fixed the login bug by deleting all accounts

## How it works

`main.ts` writes the commit message deterministically to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (default `/output`), then reads the file back and
verifies it byte-for-byte against the message, throwing if anything differs.

```sh
node main.ts
```

Requires Node 22.18 or later.
